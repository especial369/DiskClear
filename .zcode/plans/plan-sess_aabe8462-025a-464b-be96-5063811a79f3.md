## PRD v1.0 → v1.1 修订计划

**产出物**：新建文件 `D:\MyFile\MyProjects\DiskClear\DiskClear 盘清 - PRD产品需求文档 v1.1.md`（保留 v1.0 原件不动），文首增加 v1.1 修订记录表（每处改动注明对应章节和原因，便于对照评审）。

**P0 修复（4 项矛盾/缺陷）**

1. **白名单矛盾**：重构 6.2 节——不可删除目录从整目录改为"系统关键子路径 + 例外清单"机制；缩略图缓存（`...\Windows\Explorer\thumbcache_*.db`）列入允许清理的例外，并明确例外仅限具体缓存文件类型。
2. **恢复区重构**：6.1 节改为按盘符分布——被清理文件移入所在盘根下的隐藏目录（如 `D:\$DiskClear\Recovery\`，同盘 rename 零拷贝），C 盘沿用 `%LOCALAPPDATA%` 路径；5GB 上限按盘分别计算；新增恢复区被外部误删时的自愈说明；新增 FAT32 超 4GB 文件策略（增强确认后直接删除或跳过，用户可选，默认跳过）。
3. **Downloads 移出一键清理**：从 2.2 扫描项清单删除，改为仅在大文件查找/空间分析中呈现。
4. **新增 6.4 文件占用处理策略**：删除失败 → 检测占用 → 跳过并计数，结果页标注"N 项因占用跳过"；浏览器缓存清理前检测浏览器进程并提示；Windows 更新缓存检测 wuauserv 服务状态。

**P1 调整（4 项可行性风险）**

6. **3.1 性能指标加前提**：SSD 环境 200GB ≤ 60 秒，HDD 不承诺；5.3 数据结构补充聚合策略（目录级聚合统计、文件明细按需分页加载、明细条数上限）。
7. **设置中心**：定时清理、开机自启标记为 v2，明确 v1 无常驻后台进程。
8. **隐私/兼容性表述修正**：核心功能离线可用；安装包内嵌 WebView2 离线引导组件。
